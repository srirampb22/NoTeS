## How These Notes Are Structured — The Golden Circle

Every topic in this repo is explained using **Simon Sinek's Golden Circle** framework — a communication model built around starting with *purpose* before *detail*.

### The three layers

| Layer | Question | Explains |
|-------|----------|----------|
| **WHY** | Why does this exist? | The core purpose or problem it solves |
| **HOW** | How does it work? | The mechanism or approach |
| **WHAT** | What is it? | The actual components, tools, or output |

### Why this order matters

Most documentation dumps features and syntax on you first (WHAT), leaving you wondering *why you should even care*. The Golden Circle flips this — by anchoring every concept in its *reason for existing* first, the details that follow actually stick.

> Think of it like building a mental hook before hanging the details on it.

Each note in this repo follows: **WHY → HOW → WHAT** — so you always understand the motivation before the mechanics.
